# Product Management System - Frontend

A React-based web application for managing products and categories. It provides a user-friendly interface for authentication and CRUD operations.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Vite

## Features

- User signup and login
- Dashboard with category and product management
- Create, view, update, and delete categories
- Create, view, update, and delete products
- Search products
- Form validation and error handling
- Responsive UI

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

Open the local URL shown in the terminal to access the application.

## Backend

The frontend communicates with the Spring Boot backend API. Make sure the backend is running and the API URL is configured correctly.
